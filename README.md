# Levelarium v1: как выложить и пользоваться

Файлы: `index.html` (приложение), `sw.js` (автообновление и офлайн), `config.js` (пока пустой, для будущего онлайна),
`manifest.webmanifest` и четыре иконки. Загружать нужно ВСЕ файлы.

## Публикация (как Opianarium)
1. На github.com: New repository → имя `levelarium` → Public.
2. Add file → Upload files → все файлы из папки → Commit changes.
3. Settings → Pages → Deploy from a branch → `main`, `/ (root)` → Save. Через 1–2 минуты будет ссылка.
4. Установка: Chrome на Android → ⋮ → «Установить приложение». APK: pwabuilder.com (как в README Opianarium).

## Как работает
- Каждый день четыре квеста: приседания 100, отжимания 50, пресс 50, бег 3 км. Свои квесты добавляются кнопкой «+».
- Квест выполнен: +25 XP. Все квесты дня: бонус +50 XP и серия растёт.
- Пропущенный день: серия обнуляется, минус 30 XP.
- Уровень требует 100 XP + 25 за каждый следующий. Ранги: E (1–10), D, C, B, A, S (50+).
- Данные хранятся на устройстве. Онлайн и аккаунты добавим позже.

## Версии
Номер версии (сейчас v1.2) стоит в `index.html` (`VER`) и в `sw.js` (`V`). С каждым обновлением повышай оба: v1.1, v1.2 и так далее.

## Что нового в v1.1
- Квесты месяца: приседания 2000, отжимания 1000, пресс 1000, бег 60 км и 20 идеальных дней. Копятся сами из дневных квестов. Награда +150 XP (идеальные дни +300 XP) против +25 XP за дневной квест.
- Дни: «День N из M», кнопки «Следующий день» и «Вернуть день», календарь месяца в «Статистике». В начале нового месяца месячные квесты обнуляются.
- Профиль в ⚙: имя, аватарка, баннер, обои. Эффекты (дождь, туман, молнии, наклон, звук, лёгкий режим) как в Opianarium, по умолчанию выключены.
- Чтобы обновить сайт, загрузи в репозиторий новые `index.html`, `sw.js` и `README.md`.

## Что нового в v1.2
- Бонусные задания (раз в день): выполнение даёт зелье. Ранг задания задаёт длину: E 5 мин, D 10, C 15, B 30, A 60. Зелье умножает весь опыт, пока действует (×1.2 до ×2).
- Инвентарь: зелья (кнопка «Выпить») и снаряжение: кинжалы и броня дают постоянный пассивный множитель, их можно надеть и снять.
- Монстры (вкладка «Монстры»): каждого можно победить раз в день. Монстр доступен, если ранг не выше твоего и опыта всего хватает на его силу. На ранге E только слизень, паук, гоблин-разведчик и крыса. Монстры иногда дают зелья и снаряжение.
- Чтобы обновить сайт, загрузи в репозиторий новые `index.html`, `sw.js` и `README.md`.
