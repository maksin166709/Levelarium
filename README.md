# Levelarium
Levelarium: тренировки в стиле аниме. Ежедневные квесты (приседания, отжимания, пресс, бег), месячные задания с большими наградами, XP, уровни и ранги E–S. Дни и серия, календарь месяца, профиль с аватаркой и настройками эффектов. Работает без регистрации и интернета, данные хранятся на устройстве. Устанавливается как приложение через Chrome.
